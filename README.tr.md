# Altınkaya MCP

> Yapay zekâ asistanınıza [Altınkaya](https://www.altinkaya.com) elektronik kutu kataloğunun tamamını bağlayın.

[English](README.md)

**Durum: geliştirme aşamasında.** Bkz. [yol haritası](ROADMAP.md).

`altinkaya-mcp`; Claude, Cursor, VS Code Copilot ve diğer MCP istemcilerinin Altınkaya'nın
~1.300 kutusunda arama yapmasını, içine sığması gerekene göre filtrelemesini
("80 × 50 × 20 mm PCB, IP67, ABS"), modelleri karşılaştırmasını ve CAD dosyalarını
(STEP / PDF / DXF) getirmesini sağlayan bir [Model Context Protocol](https://modelcontextprotocol.io) sunucusudur.

Bilgisayarınızda çalışır, yalnızca okuma yapar; API anahtarı veya üyelik gerekmez.

## Sorumluluk reddi

Bu resmi olmayan bir topluluk projesidir; Altınkaya Elektronik Cihaz Kutuları San. Tic. A.Ş.
ile bağlantılı değildir. Ürün verileri Altınkaya'ya aittir; üretimden önce ölçüleri her zaman
resmi teknik çizimlerden doğrulayın.
