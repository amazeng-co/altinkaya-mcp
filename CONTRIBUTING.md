# Contributing

Thanks for helping improve `altinkaya-mcp`!

## Setup

Requires Node.js 22.12 or newer.

```bash
git clone https://github.com/amazeng-co/altinkaya-mcp.git
cd altinkaya-mcp
npm install
npm test
```

## Development

| Command             | What it does                          |
| ------------------- | ------------------------------------- |
| `npm run dev`       | Run the server from source over stdio |
| `npm run build`     | Compile to `dist/`                    |
| `npm run typecheck` | Type-check without emitting           |
| `npm run lint`      | ESLint                                |
| `npm run format`    | Prettier                              |
| `npm test`          | Vitest                                |

Try the server interactively with the MCP Inspector:

```bash
npm run build && npx @modelcontextprotocol/inspector node dist/index.js
```

## Pull requests

- Keep changes focused; one topic per PR.
- Add or update tests for behavior changes.
- Run `npm run lint && npm run typecheck && npm test` before pushing.
- Add a changeset for user-facing changes: `npm run changeset`.
- Write commit messages in English, in the imperative mood ("Add filter for IP rating").

## Catalog data

`data/catalog.json` is generated by the crawler. Please do not edit it by hand; fix the crawler
instead.

The crawl runs **locally, about once a month** (a scheduled workflow opens a reminder issue). It
drives a tab in your own Chrome so pages are read exactly as your browser sees them:

1. In Chrome, open `chrome://inspect/#remote-debugging` and enable remote debugging.
   Chrome asks once per run to allow the connection.
2. Try a few products first; this writes `data/catalog.sample.json` (git-ignored):

   ```bash
   npm run crawl -- --limit 5
   ```

3. Run the full crawl (one request every ~1.5 s, roughly 30–40 minutes):

   ```bash
   npm run crawl
   ```

4. Check the added / removed / changed summary, then open a PR with `data/catalog.json`.

The crawler only keeps public catalog fields (dimensions, materials, ratings, variants,
documents). It never stores prices, stock, or anything about your account; a test enforces this.
Set `ALTINKAYA_CRAWL_DELAY_MS` to change the delay and `ALTINKAYA_CDP_URL` if Chrome's debugging
endpoint is not found automatically.
