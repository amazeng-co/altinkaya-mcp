# Altınkaya MCP

> Give your AI assistant the full [Altınkaya](https://www.altinkaya.com) electronic enclosure catalog.

[Türkçe](README.tr.md)

**Status: early development.** See the [roadmap](ROADMAP.md).

`altinkaya-mcp` is a [Model Context Protocol](https://modelcontextprotocol.io) server that lets
Claude, Cursor, VS Code Copilot and other MCP clients search Altınkaya's ~1,300 enclosures,
filter them by what has to fit inside ("an 80 × 50 × 20 mm PCB, IP67, ABS"), compare models and
fetch CAD files (STEP / PDF / DXF).

It runs locally, is read-only, and needs no API key or account.
